- В версии 1.19.0 был добавлен WEB-интерфейс (HTTPS). Включен по умолчанию, для отключения (при необходимости) примените команду 'no ip http secure-server'.

- С версии 1.18.0 на коммутаторах с некорректной лицензией через 10 перезагрузок будет блокироваться переход в привилегированный режим.
В случае некорректной лицензии (выводится сообщение 'WARNING! Switch does not have valid license!' при логине на коммутатор или сообщение 'License is invalid!' в выводе команды show license) обратитесь в support.nag.ru для получения лицензии.

- С версии 1.17.0 настройки SNMP перенесены в отдельный режим конфигурации SNMP. При обновлении с более ранних версий настройки SNMP перенесутся автоматически.
При downgrade с 1.17.0 и выше на более ранние версии eNOS необходимо будет сконфигурировать все настройки SNMP заново.

- С версии 1.16.0 SNMP-community и пароли пользователей SNMP будут храниться в конфигурации коммутатора в зашифрованном виде.
При обновлении с более ранних версий настройки SNMP-community перенесутся автоматически, но SNMP пользователей потребуется завести заново
(команда 'snmp-server user <username> <role> auth (sha|md5) <password> [priv (des|aes) <password>]').
При downgrade с 1.16.0 и выше на более ранние версии eNOS необходимо задать SNMP-community и пароли пользователей SNMP заново.

- В версии 1.12.0 изменен алгоритм шифрования ключей Radius и Tacacs+ серверов, что приводит к некорректной их установке при downgrade на более ранние версии eNOS. Для корректной работы Radius и Tacacs+ после downgrade необходимо задать ключи заново. При обновлении на версию 1.12.0 с более ранних версий eNOS задавать ключи заново не требуется.

- В версии 1.7.0 изменена логика работы команды "switchport mode trunk", при её применении на порту разрешаются все Vlan. Для корректного обновления с версий 1.5.x и ниже на 1.7.0 и выше необходимо:
-- обновиться на версию 1.6.0
-- сохранить startup-config
-- обновиться на последнюю версию eNOS
